## 📱 ¿Qué es FlasChat?

**FlasChat** es una aplicación de mensajería ligera que aprovecha la infraestructura del **correo Nauta** de ETECSA para enviar y recibir mensajes instantáneos.

Fue diseñada específicamente pensando en la **comunidad cubana**, optimizando al máximo el consumo de datos para que funcione incluso con conexiones lentas o inestables, y ofreciendo una experiencia moderna similar a WhatsApp o Telegram, pero **sin depender de servidores externos**.

### 🎯 Filosofía del proyecto

- **🔒 Privacidad primero:** Todo se guarda en tu dispositivo, nada en servidores ajenos.
- **💾 Ligero:** Consume muy pocos datos, ideal para conexiones Nauta.
- **🎨 Personalizable:** Más de 40 opciones de apariencia distintas.
- **🇨🇺 Para Cuba:** Diseñado desde cero pensando en las necesidades de la comunidad cubana.
- **🚫 Sin publicidad:** Nunca habrá anuncios, ni rastreo, ni telemetría.
- **🆓 Gratis para siempre:** Sin pagos ocultos ni suscripciones.

## ✨ Características

### 🎨 Apariencia y Personalización

- **15 colores de acento** para personalizar la app: Azul, Verde, Púrpura, Rosa, Naranja, Cielo, Menta, Lavanda, Melocotón, Amarillo, Coral, Turquesa, Rosa oscuro, Lima, Índigo
- **3 modos de tema:** 🌙 Oscuro, ☀️ Claro, 💻 Automático
- **12 fondos de chat** con degradados + fondo personalizado desde galería
- **6 estilos de burbuja oscuros** con contraste adaptativo en tema claro
- **3 estilos básicos de cola:** WhatsApp, Telegram, Minimalista
- **4 estilos de fuente:** Normal, **Negrita**, *Cursiva*, `Markdown`
- **4 tamaños de letra:** Pequeña, Normal, Grande, Muy grande

### 🎯 Stickers y Emojis

- **10 packs de stickers** deslizables horizontalmente:
  - 💙 FlasChat (palabras: Hola, Gracias, Súper, Bro…)
  - 💙 FlasChat Emoji
  - 🎃 Halloween
  - 🎄 Navidad
  - 🐱 Animales
  - ❤️ Corazones
  - 😀 Smileys
  - 👍 Gestos
  - 💋 Amor
  - 🎉 Fiesta
- ⚡ **Envío automático** al pulsar un sticker (estilo Telegram)
- 🕒 Pestaña de **stickers recientes**
- **700+ emojis** organizados en 11 categorías (caritas, gestos, corazones, comida, deportes, transporte, objetos, animales, símbolos, banderas, formas)

### 💬 Mensajería Completa

- **Envío y recepción** por correo Nauta (SMTP/IMAP)
- **Reacciones con emojis** (👍 ❤️ 😂 😮 😢 🙏)
- **Editar** mensajes propios
- **Responder** deslizando hacia los lados
- **Reenviar**, copiar, eliminar
- **Selección múltiple** para borrar en lote
- **Info** detallada de cada mensaje
- **Adjuntos:** imágenes, audio, video y archivos (hasta 5 MB)
- **📷 Cámara integrada** para tomar fotos
- **🎤 Notas de voz** manteniendo pulsado el micrófono (hasta 2 min)
- **Palomitas ✓✓** de leído (estilo Delta Chat)
- **Separadores de fecha** (Hoy, Ayer, fecha completa)
- **Búsqueda** por texto y **búsqueda avanzada** con filtros

### 🔒 Seguridad y Privacidad

- **Cifrado E2E opcional** (AES-256-GCM con PBKDF2)
- **Bloqueo con PIN** de 4 dígitos
- **Todo el almacenamiento es local**
- **Sin telemetría, sin rastreo, sin publicidad**
- La **contraseña Nauta nunca se guarda** en el cliente
- **Exportar/importar respaldo** completo en JSON
- **Exportar chat** a texto plano

### 👤 Perfil y Contactos

- **Perfil completo:** avatar, alias, correo, bio, teléfono, género, horóscopo, fecha de nacimiento, provincia
- **Contactos guardados** con editar/eliminar
- **Cuentas múltiples** de Nauta
- **Favoritos** con estrella
- **Estadísticas** de uso (mensajes, stickers, tiempo)

### ⚙️ Comportamiento y Sonidos

- **Notificaciones locales** configurables
- **Vibración** ajustable
- **12 sonidos** configurables con botones de prueba
- **Modo demo** sin servidor backend
- **Sincronización** con intervalo de 15 s a 600 s
- **Chequeo automático** del backend cada 30 s
- **Reconexión automática** al volver la red

### 🎨 Interfaz y Experiencia

- **Diseño responsive** adaptado a móviles
- **PWA instalable** en pantalla de inicio
- **Long press** para menú contextual
- **Deslizar** mensaje para responder
- **Botón flotante** de scroll al final
- **Globo de notificaciones** de mensajes no leídos
- **Iconos SVG** 100% offline (sin CDN)
- **Animaciones suaves** en todas las transiciones
- **Toast** informativos con iconos

## 🚀 Cómo ejecutar en tu PC

### 📋 Requisitos previos

| Requisito | Versión | Descarga |
|-----------|---------|----------|
| **Node.js** | 18+ | [nodejs.org](https://nodejs.org/) |
| **Git** | Cualquiera | [git-scm.com](https://git-scm.com/) |
| **Cuenta Nauta** | — | `usuario@nauta.cu` |

### ⚡ Instalación rápida

```bash
# 1️⃣ Clonar el repositorio
git clone https://github.com/maniabon76-gif/flaschat.git
cd flaschat

# 2️⃣ Instalar dependencias
npm install

# 3️⃣ Configurar credenciales
cp .env.example .env
# Edita .env con tus datos de Nauta

# 4️⃣ Iniciar FlasChat
npm start
