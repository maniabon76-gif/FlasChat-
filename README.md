# FlasChat-
FlasChat nació como una solución práctica para los cubanos que usan el correo Nauta a diario. La idea es simple: aprovechar la infraestructura del correo electrónico para crear un chat ligero, sin depender de servidores externos ni consumir datos innecesarios.

La aplicación evolucionó desde un simple chat con burbujas hasta convertirse en una herramienta completa con cifrado de extremo a extremo, reacciones, adjuntos multimedia, perfiles de usuario, fondos personalizables y un sistema de respaldo que respeta la privacidad del usuario.
