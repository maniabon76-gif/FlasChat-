# Guía para contribuir a FlasChat

Gracias por tu interés. Como este es un proyecto **propietario**, ten en cuenta
lo siguiente antes de contribuir.

## Antes de empezar

1. Abre un **Issue** primero para discutir cambios grandes.
2. **Fork** del repositorio solo con autorización previa por escrito.
3. Sé amable, claro y constructivo.

## Reportar bugs

Incluye:

- Versión de FlasChat (ver Ajustes → Acerca de)
- Modelo de teléfono y versión de Android
- Pasos para reproducir el bug
- Capturas o grabación si es posible

## Sugerencias

- El problema que resolvería
- Cómo imaginas la solución
- Alternativas consideradas
